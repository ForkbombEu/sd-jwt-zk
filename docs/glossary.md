# Glossary

- **Challenge:** canonical verifier request bound into the transcript.
- **Exact key:** the locally selected issuer P-256 public key.
- **Holder-bound:** bearer relation plus bounded KB-JWT holder possession.
- **Local snapshot:** verifier-selected four-leaf status root and metadata.
- **Relation verification:** cryptographic validity without authorization.
- **Presentation verification:** relation validity plus local policy and replay.
